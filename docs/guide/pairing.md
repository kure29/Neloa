# 配对与设备信任

Neloa 不在云端建立信任。两台设备必须各自确认一次，之后才固定对方的身份密钥。

## 配对时发生了什么

1. 两端建立一个 Noise XX 握手，并协商协议版本与能力集。
2. 握手完成后，两端各自从同一份握手记录里推导出一个**六位数字**。
3. 两端的数字必须一致。你需要在两台设备上分别确认。
4. 只有双方都确认，对方的公钥才会被写入本机的信任列表。

这个数字不是密码，也不需要保密。它的作用是让"中间有人替换了连接"这件事变得可见：如果两端显示的数字不同，说明你正在和另一台设备对话。

配对页会同时展示对端的**密钥指纹**。验证码一致、指纹也一致，才可以建立信任。

::: warning 数字不一致时
不要确认。取消这次配对，确认你选中的是对面那台设备，然后重新发起。数字不同通常意味着选错了设备，而不是有人正在攻击你——但结果是同一个：这次连接不该被信任。
:::

## 配对之后

- 后续会话必须同时匹配设备 ID 与已保存的公钥，否则握手会被拒绝。
- 已配对设备在设备页会显示「局域网」或「中继」的路由标记。
- 重启应用后配对状态仍然有效，不需要重新核对数字。
- 中继不参与配对：跨网络传输的前提是先在局域网完成过一次配对。

## 设备备注

每台设备可以在本机设置一个备注，用来区分名字相近的设备（比如两台都叫 "MacBook" 的机器）。

- 在设备页点击已配对设备右侧的「更多」按钮，可以设置备注。
- 备注最多 32 个字符，不能包含控制字符。
- **备注只保存在本机**，不会修改对方的设备名称。

设备本机名称在「设置 → 本机」里修改，其他设备会看到这个名称。

## 撤销信任

设备页只显示当前在线的设备；「设置 → 设备信任」还会保留离线设备，方便你随时撤销权限。在这里对目标设备点击「移除」即可撤销信任。撤销后：

- 该设备不再出现在你的可信列表里，也不能再向你发送文件或剪贴板内容。
- 想要重新建立信任，需要两台设备重新走一次六位数字流程。

::: tip 判断是否要撤销
设备已经转手、重装系统、或者你不再确定那台机器是谁的——这些都该撤销后重新配对。**配对是信任的全部依据**，撤销它就等于把这段关系清空。
:::
