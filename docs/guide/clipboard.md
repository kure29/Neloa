# 剪贴板同步

剪贴板同步默认**关闭**。这是一个刻意的默认值：剪贴板里出现的东西往往比你预期的更敏感。

## 开启

打开「设置 → 剪贴板同步」，开启「自动同步新复制的文字」。

开启时会记录当前剪贴板内容作为本地基线，但**不会**把这段已有内容发送出去。只有开启之后新复制的文本才会同步。

## 同步的边界

| 约束 | 值 |
| --- | --- |
| 内容类型 | 仅纯文本 |
| 单条上限 | 8 KB |
| 敏感内容 | 拦截常见密钥与凭据标记，例如 `-----BEGIN PRIVATE KEY-----` |
| 持久化 | 剪贴板正文不写入记录，也不写入诊断报告 |
| 目标 | 仅当前在线的已配对设备 |

超出大小上限或命中敏感内容标记的文本**留在本机**，不会被发送。

## 回环与去重

收到的内容不会立刻被再发回去：远端写入成功后，本机会把它当作新的本地基线。为了跨平台比较，CRLF、CR 与 LF 在比较前会被统一。

## 移动端的限制

Android 10 及以后限制了后台读取剪贴板，iOS 也可能显示系统的粘贴授权提示。因此移动端的产品定义是：**应用处于前台时才同步**。系统不会允许移动端做和桌面端一样的无限后台轮询。

## 最近一次事件

设置页会在开关下方显示最近一次剪贴板事件的状态、对端、字节数与时间。如果同步没有按预期工作，先看这里——它能区分"没有新内容"和"发出去但失败了"。
