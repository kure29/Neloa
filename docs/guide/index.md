# 认识 Neloa

Neloa 在你自己的设备之间传输文件和纯文本剪贴板内容。它优先使用局域网直连，设备不在同一网络时，也可以通过你自己的中继服务器建立连接。

## 三个关键决定

**不需要账号。** 设备身份是一对长期密钥，保存在系统的安全凭据库里：macOS 与 iOS 用 Keychain，Windows 用凭据管理器，Android 用 Keystore。没有服务端替你保管身份，也就没有服务端可以拿它做别的事。

**局域网优先。** 同一网络下，设备之间通过 QUIC 直连，发现靠 mDNS/Bonjour（服务名 `_neloa._udp.local.`，传输端口 UDP 48631）。发现到局域网地址时不会静默改走中继；只有已配对设备没有局域网路由时才使用中继。

**端到端加密。** 传输层之上的每一段应用数据都由 Noise XX 保护，长期设备私钥参与身份认证。中继能看到在线设备元数据、流量的时间与大小，但拿不到明文。

## 平台支持

| 平台 | 客户端 | 说明 |
| --- | --- | --- |
| macOS | Universal DMG | 兼容 Apple Silicon 与 Intel |
| Windows | x64 NSIS | Windows 10 1803 及以上通常已带 WebView2 |
| Android | ARM64 APK | 用于主流 Android 真机 |
| iOS | 未签名 IPA | 需要用自己的证书与描述文件重签 |

## 30 秒上手

1. 在两台设备上打开 Neloa；局域网使用时让它们连接同一个网络。
2. 在设备页选择要连接的设备，核对两端显示的六位数字，并分别确认配对。
3. 选择一个或多个文件；macOS 与 Windows 也可以把文件直接拖进窗口。
4. 检查待发送列表并点击发送，接收端需要明确接受每个文件。
5. 接收的文件会保存到系统下载目录的 `Neloa` 文件夹。

跨网络使用前，先在局域网完成一次配对，再在两端配置同一个自建中继。细节见[自建中继](/guide/relay)。
